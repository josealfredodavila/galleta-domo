🍪 Sariel's Ecosistema WEB3

Plataforma Web3 integral que combina comercio físico, activos digitales, red social, marketplace, transmisiones en vivo, mensajería, pagos cripto y servicios digitales en un mismo ecosistema.

---

📋 Descripción

Sariel's Ecosistema conecta productos físicos, tecnología Web3 y servicios digitales mediante una arquitectura moderna basada en Node.js, Express, Supabase, Polygon y Railway.

El ecosistema incluye:

- 🏠 Domos de galleta con QR únicos
- 🪙 ES.TOKS sobre Polygon
- 🎁 NFTs asociados al sistema de recompensas
- 👤 Perfiles y red social
- 📰 Muro social
- 💬 Mensajería en tiempo real
- 🎥 Live Streaming
- 🛒 Mercado, marketplace de productos y servicios
- 🚴 Sistema de repartidores
- 💳 Pagos con NOWPayments
- 📱 eSIM mediante Telnyx
- 🤖 Funciones de IA y asistente
- 🔐 Seguridad, autenticación y protección de datos

💵 Pago de entrega

Durante la primera fase:

El comprador paga directamente al repartidor el costo de la entrega.

Mercado no aplica comisión sobre la venta de productos durante esta fase.

La arquitectura queda preparada para incorporar posteriormente un sistema de comisiones.

🚀 Despliegue

El backend está preparado para ejecutarse en Railway.

Instalación local

# Clonar repositorio
git clone https://github.com/tuusuario/sariels-ecosistema.git

# Entrar al proyecto
cd sariels-ecosistema

# Instalar dependencias
npm install

# Configurar variables de entorno
cp .env.example .env

# Ejecutar en desarrollo
npm run dev

Producción

npm start

🧩 Principios de arquitectura

El desarrollo del ecosistema sigue varios principios:

🔒 Seguridad primero

Los secretos permanecen en variables de entorno y las operaciones sensibles se ejecutan en backend o mediante funciones protegidas.

🧱 Módulos independientes

Cada funcionalidad debe mantenerse separada para reducir dependencias innecesarias.

🗄️ Cambios controlados de base de datos

Los nuevos módulos deben evitar modificar tablas existentes cuando no sea necesario.

⚡ Realtime

Las funcionalidades que requieren actualización inmediata utilizan Supabase Realtime o LiveKit según el caso.

📱 Diseño multiplataforma

La interfaz está desarrollada con tecnologías web estándar y está orientada a funcionar correctamente en dispositivos móviles.

🌎 Preparación internacional

La arquitectura contempla múltiples idiomas, monedas, países y operaciones internacionales.
