◈ Cómo instalar la eSIM
  1. iPhone (iOS 17.4 o más): toca "Instalar en este iPhone".
  2. Android: Ajustes → Red e internet (o Conexiones) → SIM → Agregar eSIM → ingresar manualmente, y pega el código copiado.
  3. Si tienes otro dispositivo, también puedes escanear el QR desde él.
  4. Activa la línea de datos de la eSIM y quita los datos de tu otro chip si quieres usar solo estos gigas.

No puedes escanear el QR con el mismo celular donde lo estás viendo; usa el botón o el código copiado.
